The Architecture Stack

Moving beyond static image matching. Cipher uses a gloss-free pipeline to map spatiotemporal matrices directly into semantic embeddings.

TARGET OS: Cross-Platform Edge

COMPILER: LLVM / Rustc

01

Kinetic Extraction

Extracts 3D skeletal landmarks (face, hands, pose) via Python and OpenCV, discarding heavy RGB data to preserve privacy and minimize payload.

PYTHON MEDIAPIPE
02

Neural Translation

A custom Transformer network written in PyTorch maps time-series coordinate arrays directly into natural language arrays, bypassing intermediate glossing.

PYTORCH GO (WEBRTC)
03

Edge Optimization

To remove cloud-dependency, the final inference engine is compiled in C++/Rust via ONNX, allowing deployment on standard hospital tablets offline.

C++ / RUST ONNX
